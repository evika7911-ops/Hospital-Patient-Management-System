# Hospital Patient Management System

A lightweight, terminal-based Hospital Patient Management System written in Python using SQLite3 for persistence. Built for deployment and execution in Visual Studio Code.

---

## Features

- **Add New Patient**: Record basic personal details, contact info, medical condition, and assigned doctor.
- **View Patients**: List all registered patients with their status.
- **Search Record**: Fetch complete details of a specific patient using their unique ID.
- **Update Patient Details**: Modify existing fields with full fallback support.
- **Status Management**: Track whether a patient is Admitted, Discharged, or Under Observation.
- **Delete Record**: Remove records with interactive confirmation safety.
- **Database Persistence**: Automatic setup and storage using SQLite (`hospital.db`).
